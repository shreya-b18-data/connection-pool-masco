Connection Pool and MASCO

Five graph algorithms recommend new connections. MASCO combines them by consensus. Every number on this page is measured live on a synthetic social graph by hiding some real connections and checking whether each method recovers them.

Press Run. A 120-user graph takes a few seconds.

Results on hidden connections

Precision@k: share of the k recommendations that were hidden real connections. Diversity: how many different clusters appear in the list. Runtime is per user on this device.
